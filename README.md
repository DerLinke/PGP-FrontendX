# PGP-FrontendX

Eine sichere, Web-basierte grafische Oberfläche für PGP-Verschlüsselung und Entschlüsselung.
Das gesamte Krypto-System läuft 100% lokal im Browser über OpenPGP.js – keine privaten Schlüssel oder Klartext-Dateien verlassen jemals deinen Rechner!

## Features
- Verschlüsselung von Texten und Dateien
- Entschlüsselung
- Verwaltung von öffentlichen und privaten Schlüsseln (Browser Storage)
- Modernes, responsives Design (Glassmorphism & Dark Mode)

## Setup
Einfach auf einen Webserver hochladen oder lokal mit einem PHP-Server starten.
